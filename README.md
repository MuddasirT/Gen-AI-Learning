# Generative AI Learning Journey

A practical, 30-day learning journey toward understanding and building AI systems, documented by **Muddasir**.

## Learning approach

Each day combines:
- Core concepts explained from first principles
- A practical, runnable example
- A small experiment or knowledge check
- Notes on what worked, what failed, and why
- A GitHub learning log
